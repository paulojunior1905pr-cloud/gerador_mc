# Gerador de MC – Tanques RNEST

Site para montar as Memórias de Cálculo (MC) do contrato 5900.0128196.24.2 e baixar em Excel com fórmulas e fotos.

- As MCs e fotos ficam salvas no navegador do aparelho em que o site é usado.
- Use **Baixar backup** / **Restaurar backup** (rodapé) para levar os dados para outro aparelho.
- Publicado via GitHub Pages (Settings > Pages > branch `main`, pasta `/ (root)`).
